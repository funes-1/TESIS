Configuración requerida de Firebase

El administrador debe activar Email/Password en Authentication, crear las cuentas y publicar reglas de acceso por usuario. El HTML no puede modificar las reglas del servidor. Para el login, alojá este archivo en HTTPS o localhost y autorizá el dominio en Firebase. La carga, edición y respaldo local no requieren login.

Los datos antiguos de goniometria/principal no se leen ni se borran automáticamente. Para migrarlos, restaurá un respaldo local y revisá la sincronización de tu cuenta. Cerrá el acceso al documento antiguo desde la consola. Las claves de configuración web son públicas; no reemplazan las reglas de acceso.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/goniometria/{docId} {
      allow read, write: if request.auth != null
                        && request.auth.uid == uid;
    }
    match /goniometria/{docId} {
      allow read, write: if false;
    }
  }
}

Si el proyecto aloja otras aplicaciones, integrá estas reglas conservando sus permisos específicos. Eliminá cualquier regla global que permita acceso público: las reglas permisivas se suman.
